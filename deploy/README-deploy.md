# АПС — лендинг: деплой на Vercel

Готовая к деплою статическая сборка + serverless-функция для приёма заявок в Telegram.

## Что внутри

```
deploy/
├─ index.html                 лендинг (React + support.js подключены локально)
├─ support.js                 рантайм Claude Design (dc-runtime)
├─ vendor/
│  ├─ react.production.min.js        React 18.3.1 UMD (локально, без CDN)
│  └─ react-dom.production.min.js    ReactDOM 18.3.1 UMD
├─ uploads/                   картинки лендинга
├─ api/
│  └─ apply.js               функция: форма → Telegram
├─ vercel.json
└─ .gitignore
```

Всё self-hosted: внешних CDN нет, интернет нужен только для шрифтов Google Fonts.

## Что нового по сравнению с исходником

1. **Форма заявки реально отправляется в Telegram.** Кнопка «Отправить заявку» шлёт данные на `/api/apply`, показывает «Отправляем…», а «Заявка отправлена» появляется **только после реального успеха**. При ошибке — сообщение под кнопкой.
2. **Cookie-баннер** внизу экрана по дизайну АПС: «Принять» / «Только необходимые», выбор запоминается в `localStorage` (ключ `aps-cookie-consent`), повторно не показывается.

## Шаг 1. Создать Telegram-бота и получить chat_id (для группы)

1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя и username. Получите **токен** вида `123456789:AAE...`.
2. Создайте группу (или используйте существующую) и **добавьте туда бота**.
3. Чтобы бот видел сообщения группы, у @BotFather отключите приватность: `/setprivacy` → выберите бота → **Disable**. (Для простой отправки заявок это не обязательно, но не помешает.)
4. Узнать **chat_id группы**:
   - отправьте любое сообщение в группу;
   - откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`;
   - найдите `"chat":{"id":-100XXXXXXXXXX,...}` — это и есть `chat_id` (у групп/супергрупп он **отрицательный**).

## Шаг 2. Задать переменные окружения в Vercel

В проекте на Vercel → **Settings → Environment Variables** добавьте (для Production и Preview):

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_ID`   | id группы (напр. `-1001234567890`) |

> Токен — секрет. Не коммитьте его в репозиторий, храните только в переменных Vercel.

## Шаг 3. Деплой

**Вариант А — через веб-интерфейс:** залейте содержимое папки `deploy/` в Git-репозиторий и импортируйте его в Vercel. Framework preset: **Other**. Root Directory: папка с этим `index.html`.

**Вариант Б — через CLI:**
```bash
npm i -g vercel
cd deploy
vercel            # первый раз — привязка проекта
vercel --prod     # прод-деплой
```
Переменные окружения можно добавить и из CLI: `vercel env add TELEGRAM_BOT_TOKEN`.

## Проверка после деплоя

- Откройте сайт, пролистайте до формы, заполните и отправьте — в группе должно появиться сообщение «Новая заявка — АПС».
- Если приходит ошибка: проверьте, что обе переменные заданы и что бот добавлен в группу, а `chat_id` именно этой группы.

## Осталось заменить (плейсхолдеры лендинга)

- В футере: `[телефон]`, `[email]`, реальные ссылки на документы.
- Ссылка «Политика конфиденциальности» в cookie-баннере сейчас ведёт на `#apply` — поставьте реальный URL/файл политики, когда он будет.
